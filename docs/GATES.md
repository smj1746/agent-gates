# 오류 게이트

같은 오류를 두 번 고쳐도 남으면 작업을 멈추고, 해결한 뒤 아래 형식으로 등록합니다.
에이전트는 초안만 쓰고, 사람이 승인한 것만 이 파일에 올립니다.
작업을 시작할 때 '상태: 활성'인 게이트를 먼저 읽습니다.

아직 등록된 게이트가 없습니다. (`agent-gates check`가 `gates/empty` 경고를 내는 것은 정상입니다)
